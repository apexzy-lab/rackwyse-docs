Cloud Connections

Connect your cloud accounts to Rackwyse for streamlined analysis. Connections are read-only and never modify your infrastructure.

ℹ️
Connections vs manual uploads
You do not need to connect a cloud account to use Rackwyse. You can always upload billing exports manually. Cloud connections are optional and make the upload process faster.

☁️ AWS IAM Role Setup

Rackwyse uses an IAM Role with read-only billing permissions to access your AWS cost data. This is the most secure method — no access keys are stored, and permissions are limited to billing data only.

Required permissions

The IAM role requires only the following read-only policies:

  • ce:GetCostAndUsage — read cost and usage data
  • ce:GetDimensionValues — read service dimension data
  • aws-portal:ViewBilling — view billing console data
💡
Read-only access only
Rackwyse never requests write permissions. The role cannot create, modify, or delete any AWS resources. It can only read billing and cost data.

Setup steps

1
Go to Connections in Rackwyse
Click Connections in the left sidebar. Click Connect AWS. Note the External ID shown — you will need this in the next steps.
2
Open IAM in AWS Console
Log in to the AWS IAM Console. Go to Roles → Create Role.
3
Configure the trust relationship
Select Another AWS account as the trusted entity. Enter the Rackwyse AWS Account ID shown on the Connections page. Check Require external ID and enter the External ID from step 1.
4
Attach the billing policy
On the Permissions page, click Create Policy. Paste in the read-only billing policy JSON shown on the Connections page. Give the policy a name like RackwyseReadOnlyBilling.
5
Name and create the role
Give the role a name like RackwyseRole and create it. Copy the Role ARN from the role summary page (it looks like arn:aws:iam::123456789012:role/RackwyseRole).
6
Paste the ARN in Rackwyse
Back in the Rackwyse Connections page, paste the Role ARN and click Connect. Rackwyse will verify the connection and confirm it is working.

🔵 GCP Connection

GCP connections use a Service Account with read-only billing viewer permissions. The connection setup guide is available on the Connections page in your Rackwyse account.

🔷 Azure Connection

Azure connections use OAuth with a read-only Cost Management Reader role. Click Connect Azure on the Connections page and follow the OAuth flow to grant read-only access.
