Cloud Connections

Connect your cloud accounts for automatic monthly billing syncs. All connections are read-only — Rackwyse never modifies your infrastructure.

ℹ️
Connections vs manual uploads: You do not need to connect a cloud account to use Rackwyse. Connections enable automatic monthly syncs and utilization-based findings (idle instances, over-provisioned resources via CloudWatch).

☁️ AWS — IAM Role

Rackwyse uses an IAM Role with read-only billing and CloudWatch permissions. No access keys stored — Rackwyse assumes your role via STS with a unique External ID.

Required IAM policies

  • AWSCostExplorerReadOnlyAccess — read billing and cost data
  • CloudWatchReadOnlyAccess — enables idle/oversized EC2 detection via real utilization data

Setup steps

1

Open Connections in Rackwyse

Click Connections in the sidebar. Note the External ID — you need it below.

2

Create an IAM Role in AWS

Go to AWS IAM Console → Roles → Create Role. Select Another AWS account, enter the Rackwyse Account ID shown on the Connections page, check Require external ID, and paste the External ID.

3

Attach required policies

Attach AWSCostExplorerReadOnlyAccess and CloudWatchReadOnlyAccess.

4

Name and create the role

Name it RackwyseReadOnly. Copy the Role ARN from the summary page.

5

Paste the ARN in Rackwyse

Back in Rackwyse Connections, paste the Role ARN and click Connect. Connection is verified immediately.

💡
AWS connections auto-sync on the day of month you configure. Click Sync Now for an immediate analysis at any time.

🔵 GCP — OAuth + BigQuery

GCP connections use Google OAuth with read-only billing access. After connecting, Rackwyse queries your Cloud Billing BigQuery export.

Prerequisites

  • Enable Cloud Billing API in your GCP project
  • Enable BigQuery billing export in GCP Console → Billing → Billing export → BigQuery export
  • Wait 24–48 hours for first data to appear after enabling export

Setup steps

1

Click "Connect with Google"

On the Connections page, click Connect with Google and complete the OAuth flow. Grant read-only billing access.

2

Enter your BigQuery details

A setup modal appears after OAuth. Enter:
• GCP Project ID — project containing your billing export
• BigQuery Dataset Name — dataset where billing export is configured
• Region — US, EU, etc.

3

Save and enable sync

Click Save & Enable Sync. If the BigQuery table has no data yet, the connection stays active and syncs automatically once data populates.

⚠️
BigQuery billing export only captures usage going forward from when you enable it. Allow 24–48 hours for first data to appear.

🔷 Azure — OAuth

Azure connections use Microsoft OAuth with Cost Management Reader role on your subscription.

1

Click "Connect with Microsoft"

On the Connections page, click Connect with Microsoft. Sign in with your Azure account and grant the read-only permissions requested.

2

Connection verified

Rackwyse detects your subscription and begins the first sync. You are redirected to the Connections page showing your subscription ID and sync status.

Auto-sync settings

Each connection has an Auto-sync toggle and a configurable sync day (1st–28th). When enabled, Rackwyse pulls billing data on that day and runs a new analysis automatically. Anomaly alerts fire if spend increases significantly.

Disconnecting

Click Disconnect on the Connections page. For AWS, also delete the IAM role in your AWS console to fully revoke access.
