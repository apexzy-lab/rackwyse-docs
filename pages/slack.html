Slack Integration

Post analysis results, anomaly alerts, and weekly summaries to your Slack channel via webhook.

What Rackwyse posts to Slack

  • Analysis complete — when a new analysis finishes
  • Anomaly alerts — when spend spikes 15%+ month-over-month
  • Auto-sync complete — summary from automatic monthly syncs

Each message includes provider, billing period, total spend, potential savings, top 5 findings, and a direct dashboard link.

Setup steps

1

Create a Slack Incoming Webhook

Go to api.slack.com/apps → Create New App → From Scratch. Under Incoming Webhooks, activate and add to a channel. Copy the webhook URL.

2

Add webhook URL to Rackwyse

Go to Account → Preferences → Integrations. Paste the webhook URL and click Save.

3

Test the connection

Click Test — a test message will appear in your Slack channel.

Generic webhook

Rackwyse also supports a Generic Webhook URL for PagerDuty, Teams, Discord, or custom endpoints. The payload is a JSON object with event, timestamp, analysis, findings, and dashboardUrl.
