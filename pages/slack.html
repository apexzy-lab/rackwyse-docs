Slack Integration

Post analysis results, anomaly alerts, and weekly summaries directly to your Slack channel via webhook.

What Rackwyse posts to Slack

  • Analysis complete — when a new analysis finishes (upload or auto-sync)
  • Anomaly alerts — when spend spikes 15%+ month-over-month
  • Auto-sync complete — summary of findings from automatic monthly syncs

Each Slack message includes provider, billing period, total spend, potential savings, top 5 findings, and a direct link to the dashboard.

Setting up the webhook

1

Create a Slack Incoming Webhook

Go to api.slack.com/apps → Create New App → From Scratch. Name it "Rackwyse". Under Incoming Webhooks, activate and add to a channel. Copy the webhook URL.

2

Add webhook URL to Rackwyse

Go to Account → Preferences → Integrations. Paste the webhook URL in the Slack Webhook URL field and click Save.

3

Test the connection

Click Test next to the Slack webhook URL. A test message will appear in your Slack channel confirming the connection works.

Generic webhook

In addition to Slack, Rackwyse supports a Generic Webhook URL for integrating with any webhook-compatible service (PagerDuty, Teams, Discord, custom endpoints).

The generic webhook payload is a JSON object with:

  • event — event type (e.g. analysis.complete)
  • timestamp — ISO 8601 timestamp
  • analysis — provider, period, totalSpend, potentialSavings, findingsCount
  • findings — array of top findings with ruleId, title, severity, estimatedSavings
  • dashboardUrl — direct link to the analysis
