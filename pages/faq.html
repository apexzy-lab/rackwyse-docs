Frequently Asked Questions

Answers to common questions. Can't find what you need? Email support@rackwyse.com.

General

How does Rackwyse detect waste?

Rackwyse runs your billing data through 99 detection rules across AWS, GCP, and Azure. Rules check for known waste patterns: idle resources, oversized instances, missing reservations, unused commitments, misconfigured services, and more. For connected AWS accounts with CloudWatch access, additional utilization-based rules check actual CPU and memory usage to detect idle and over-provisioned instances.

Do I need to give Rackwyse access to my cloud account?

No. You can use Rackwyse entirely by uploading billing CSV exports — no cloud credentials required. Cloud connections are optional and enable automatic monthly syncs and utilization-based findings.

Can Rackwyse make changes to my cloud infrastructure?

No. Rackwyse is a read-only analysis tool. It never modifies, deletes, or creates any cloud resources. All changes must be made by you using the provided CLI commands or console steps.

Analysis & Findings

How many findings will I see on the free tier?

Free and trial accounts see 5 full findings with complete details. Remaining findings are shown as locked cards with the savings amount visible. The total locked savings are displayed in an upgrade prompt.

How many analysis can I run per month?

Starter: 3/month. Pro: 20/month. Team: 100/month. Limits reset on the 1st of each month.

Why do I see different findings on different analyses?

Findings are generated fresh from each billing export. Changes in your infrastructure — fixed issues, new resources, changed spending — affect which rules fire. If you fixed a finding, it should no longer appear in the next analysis.

What is the accuracy of savings estimates?

Savings estimates are calculated from your actual billing data using known discount rates and typical optimization benchmarks. They represent realistic savings if the fix is applied — not guaranteed figures. Actual savings depend on your specific usage patterns and implementation.

Cloud Connections

Is my cloud data secure?

Yes. All data is transmitted over HTTPS (TLS 1.2+). For AWS connections, Rackwyse stores only the IAM Role ARN — no access keys or secret keys. For GCP/Azure, encrypted OAuth tokens are stored. You can revoke access at any time by deleting the IAM role or revoking the OAuth token.

Why does my GCP connection show "waiting for data"?

GCP BigQuery billing export only populates going forward from when you enable it. If you just enabled it, wait 24–48 hours for the first data to appear. The connection will sync automatically once data is available.

Why does my Azure connection show a rate limit error?

Azure Cost Management API has rate limits on free trial subscriptions. Rackwyse retries automatically with backoff. Real paid Azure subscriptions have much higher limits and will not hit this issue.
