API Access

The Rackwyse REST API lets you submit billing CSVs and retrieve findings programmatically. Available on Team and Enterprise plans.

ℹ️
API access is available on Team and Enterprise plans.

Generating an API key

  1. Go to Account → API Access
  2. Click Generate API Key
  3. Copy the key immediately — it is only shown once

API keys start with rw_live_. Keep them secure and do not commit them to source control.

Authentication

Include your API key in the x-api-key header on all requests:

x-api-key: rw_live_your_key_here

Base URL

https://app.rackwyse.com/api/v1

Endpoints

GET /api/v1/status

Returns your account status and plan information.

curl https://app.rackwyse.com/api/v1/status \
  -H "x-api-key: rw_live_your_key"

GET /api/v1/analyses

Returns a list of your past analyses with summary data.

curl https://app.rackwyse.com/api/v1/analyses \
  -H "x-api-key: rw_live_your_key"

POST /api/v1/analyse

Submit a billing CSV for analysis. Returns findings JSON.

curl -X POST https://app.rackwyse.com/api/v1/analyse \
  -H "x-api-key: rw_live_your_key" \
  -F "file=@/path/to/billing.csv" \
  -F "provider=aws"

Response format

{
  "analysisId": "abc123",
  "provider": "aws",
  "billingPeriod": "May 2026",
  "totalSpend": 1464.66,
  "potentialSavings": 783.47,
  "findingsCount": 21,
  "findings": [
    {
      "ruleId": "EC2_NO_RESERVED",
      "title": "On-Demand EC2 running 24/7 — switch to Reserved Instance",
      "severity": "critical",
      "service": "EC2",
      "estimatedSavings": 100.80,
      "fixDifficulty": "easy",
      "fixTimeMinutes": 15
    }
  ]
}

Rate limits

API requests are rate limited to 200 requests per 15 minutes. The x-ratelimit-remaining header shows your remaining quota.

Revoking an API key

Go to Account → API Access → Revoke Key. The key is invalidated immediately.
