Anomaly Alerts

Rackwyse automatically detects unusual cloud spend and alerts you before costs spiral.

Three types of monitoring

1. Month-over-month spike detection

Every time an analysis completes, Rackwyse compares current spend to the previous analysis. If spend changed by 15% or more, an email alert fires automatically.

2. Daily anomaly check

For active AWS connections with CloudWatchReadOnlyAccess, Rackwyse runs a daily check at 02:00 UTC. Compares 7-day rolling average. If daily spend is up 30% or more, an alert fires.

ℹ️
Daily anomaly checks require an active AWS cloud connection with CloudWatch permissions. CSV-only users receive month-over-month alerts only.

3. Spend velocity widget

Dashboard shows per-provider month-over-month arrows and percentage changes. Visual indicator only.

Slack alerts

If you have a Slack webhook configured, anomaly alerts also post to your Slack channel automatically.

Disabling alerts

Go to Account → Preferences → Email Notifications and toggle off Cost Spike Alerts.
