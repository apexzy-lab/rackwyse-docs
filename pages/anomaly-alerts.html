Anomaly Alerts

Rackwyse automatically detects unusual cloud spend and alerts you before costs spiral out of control.

How anomaly detection works

Rackwyse runs three types of spend monitoring:

1. Month-over-month spike detection

Every time a new analysis completes (via upload or auto-sync), Rackwyse compares the current spend to the previous analysis for the same provider. If spend changed by 15% or more in either direction, an email alert fires automatically.

The email shows:

  • Current vs previous month spend
  • Dollar delta and percentage change
  • New findings identified in the current period
  • Link to the full analysis

2. Daily anomaly check

For active AWS connections with CloudWatchReadOnlyAccess, Rackwyse runs a daily check at 02:00 UTC. It compares the 7-day rolling average spend to the previous 7 days. If daily spend is up 30% or more, an alert email fires immediately.

ℹ️
Daily anomaly checks require an active AWS cloud connection with CloudWatch permissions. CSV-only users receive month-over-month alerts only.

3. Spend velocity tracker

The dashboard shows a Spend velocity widget with per-provider month-over-month arrows and percentage changes. This is a visual indicator — no action required.

Alert email format

Anomaly alert emails are sent to the account owner's email address. They include:

  • Provider and billing period
  • Spend comparison (before → after)
  • Delta amount and percentage
  • Direction indicator (spike vs reduction)
  • Direct link to dashboard

Slack alerts

If you have a Slack webhook configured, anomaly alerts also post to your Slack channel automatically.

Disabling alerts

To disable anomaly alert emails, go to Account → Preferences → Email Notifications and toggle off Cost Spike Alerts.
