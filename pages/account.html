Account Settings

Manage your profile, security, notifications, and integrations.

Profile

Go to Account → Profile to update your name and email address.

Security

Go to Account → Security to:

  • Change your password
  • Enable two-factor authentication (2FA) via TOTP authenticator app (Google Authenticator, Authy, etc.)
  • View and revoke active sessions
ℹ️
2FA is enforced for admin and superadmin accounts and strongly recommended for all users.

Email notifications

Go to Account → Preferences → Email Notifications to manage:

  • Monthly Summary — monthly digest of cloud spend and savings
  • Analysis Complete — email when analysis finishes
  • Cost Spike Alerts — anomaly detection emails
  • Monthly Bill Reminder — reminder to upload your bill on a configured day of the month
  • Product Updates — new features and announcements

Integrations

Go to Account → Preferences → Integrations to configure:

  • Slack Webhook URL — post analysis results and alerts to Slack
  • Generic Webhook URL — send events to any webhook endpoint

See the Slack Integration guide for full setup instructions.

API access

Go to Account → API Access to generate API keys for the Rackwyse REST API. Available on Team and Enterprise plans. See the API documentation for endpoints and usage.

Theme

Toggle between dark and light theme using the sun/moon icon in the top navigation bar, or in Account → Preferences → Appearance.

Deleting your account

To delete your account and all associated data, email support@rackwyse.com. Deletion requests are processed within 30 days.
