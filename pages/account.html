Account

Account Settings

Manage your profile, security settings, API access, and notification preferences.

Profile

Update your name and view your account email in Account → Overview. Your email address cannot be changed after registration. If you need to change your email, contact support@rackwyse.com.

Changing your password

1
Go to Security section
In your account page, click Security in the sub-navigation.
2
Enter current and new password
Enter your current password, then your new password (minimum 8 characters). A password strength indicator shows how strong your new password is.
3
Save changes
Click Update Password. You will remain logged in on your current device. Other active sessions will be logged out.

Forgot your password?

If you cannot log in, go to app.rackwyse.com/forgot-password and enter your email address. You will receive a password reset link valid for 1 hour.

Two-Factor Authentication (2FA)

Two-Factor Authentication adds a second layer of security to your account. After entering your password, you will be prompted for a 6-digit code from an authenticator app.

ℹ️
2FA is required for admin accounts
If your account has admin or superadmin role, 2FA is mandatory. You will be prompted to set it up on your first login.

Enable 2FA

1
Go to Security → Two-Factor Authentication
In your account Security section, click Enable 2FA.
2
Scan the QR code
Open your authenticator app (Google Authenticator, Authy, or any TOTP-compatible app) and scan the QR code shown on screen.
3
Enter the verification code
Enter the 6-digit code from your authenticator app to confirm the setup. Save your backup codes in a secure location.

API Keys

API keys allow you to access Rackwyse data programmatically. They are available on Pro and Team plans.

Creating an API key

Go to Account → API Access. Click Generate New Key. Give your key a descriptive label (e.g. "CI/CD pipeline" or "Slack integration"). Copy the key immediately — it will not be shown again after you close the dialog.

⚠️
Treat API keys like passwords
Do not commit API keys to version control or share them publicly. If a key is compromised, revoke it immediately and generate a new one.

Revoking an API key

To revoke a key, click the Revoke button next to it in Account → API Access. The key will stop working immediately. This cannot be undone.

Appearance

Rackwyse supports light and dark mode. Click the theme toggle button (sun/moon icon) in the top bar to switch between modes. Your preference is saved to your browser.
