Fix Commands

Every Rackwyse finding includes an exact CLI command. Copy, paste, run.

The three fix tabs

  • CLI — copy-paste AWS CLI, gcloud, or az CLI command pre-filled with your resource ID
  • Console Steps — step-by-step instructions for the cloud web UI
  • Official Docs — link to cloud provider documentation
⚠️
Always review CLI commands before running, especially for destructive operations. Create a snapshot before making infrastructure changes.

Finding ownership

  1. Expand the finding
  2. Click Assign, enter team member email, set due date
  3. Change status to In Progress

Marking as fixed

After applying a fix, change status to Done. The confirmed savings are added to your Savings Tracker total.

Coverage

Fix commands exist for all 99 detection rules — 40 AWS, 31 GCP, and 25 Azure. Placeholder values are shown as <value>.

Before running a fix

  • Verify the finding — confirm the resource is genuinely unused or oversized
  • Check for dependencies — ensure nothing relies on the resource
  • Schedule changes during low-traffic windows
  • Set to Snoozed if you need more time to investigate
