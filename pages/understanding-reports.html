Understanding Your Report

Your Rackwyse report shows every waste pattern found in your billing data, ranked by potential savings. Here is how to read it.

The dashboard overview

After an analysis completes, the dashboard shows four key metrics at the top:

  • Waste Identified — total potential monthly savings across all findings
  • Total Findings — number of waste patterns detected
  • Latest Monthly Spend — your total cloud spend for the analysed period
  • Reports on File — number of analyses stored in your account

Spend velocity tracker

The Spend velocity widget shows month-over-month spend comparison per provider. Green arrows indicate spend is down vs last month. Red arrows indicate spend is up. This updates automatically when new analyses complete.

Priority stack

Below the metrics, Your top 5 actions this week shows the highest-ROI findings ranked by savings divided by effort. This is the best place to start — fix these 5 things first.

Findings list

Each finding in your report includes:

  • Severity — Critical, High, Medium, or Low
  • Title — plain-English description of the waste pattern
  • Description — detailed explanation of why this is waste and what is causing it
  • Estimated savings — monthly dollar amount if the issue is fixed
  • Fix effort — Easy (~10 min), Medium (~30 min), or Hard (~60+ min)

Severity levels

SeverityMeaningTypical action
🔴 CriticalHigh-confidence waste with significant savings potentialFix this week
🟡 HighClear waste, straightforward fixFix this sprint
🔵 MediumLikely waste, requires verificationReview and fix if confirmed
⚪ LowPossible optimisation, low impactFix when convenient

Expanding a finding

Click the arrow on any finding to expand it and see:

  • CLI tab — exact copy-paste command to fix the issue (see Fix Commands)
  • Console Steps tab — where to go in the cloud UI to make the change
  • Docs link — official cloud provider documentation
  • Assign — assign the finding to a team member with a due date
  • Status — mark as Open, In Progress, Done, or Snoozed

Free tier limits

On the free tier, you see 5 full findings with complete details. Remaining findings are shown as locked cards with the savings amount visible. Upgrade to unlock all findings.

PDF report

Click PDF Report on any analysis to download a professionally formatted report suitable for sharing with your CFO or engineering leadership. The report includes all findings, fix instructions, and a savings summary page.

Sharing a report

Click Share to generate a public read-only link to your analysis. The link shows findings and savings estimates without requiring login. You can revoke the link at any time.
