Uploading Bills

Upload your first cloud bill

Export your billing data from AWS, GCP, or Azure and upload it to Rackwyse for analysis. No API keys or cloud credentials required.

💡
No credentials needed
Rackwyse analyses billing export files — plain CSV files you download from your cloud console. You never need to give Rackwyse API keys, IAM credentials, or cloud access permissions just to upload a bill.
☁️ AWS Cost & Usage Report 🔵 GCP Billing Export 🔷 Azure Usage CSV

☁️ Amazon Web Services (AWS)

AWS provides billing data through the Cost & Usage Report (CUR) — a detailed CSV file containing every line item on your bill. Here is how to download it.

Option 1 — AWS Billing Console (quickest)

1
Open AWS Billing
Log in to the AWS Billing Console. You need access to the root account or a user with aws-portal:ViewBilling permission.
2
Go to Bills
In the left navigation, click Bills. Select the month you want to analyse from the date picker at the top.
3
Download CSV
Click the Download CSV button at the top right. Save the file to your computer.
4
Upload to Rackwyse
Go to your Rackwyse dashboard, click + Upload Bill, and select the CSV file you just downloaded.

Option 2 — Cost & Usage Report (most detailed)

For a more detailed analysis, use the full Cost & Usage Report. This provides resource-level detail including instance IDs, regions, and usage types.

1
Open Cost & Usage Reports
In the AWS Billing Console, click Cost & Usage Reports in the left navigation, then click Create report if you have not set one up already.
2
Configure the report
Give it a name, enable Include resource IDs, and set the time granularity to Daily. Choose an S3 bucket for delivery.
3
Download from S3
Once the report is delivered (usually within 24 hours), navigate to your S3 bucket, find the report file, and download it. The file will be a .csv.gz or .csv file.
4
Upload to Rackwyse
Upload the CSV file directly. If the file is gzip-compressed (.csv.gz), decompress it first using any archive tool.
ℹ️
Which month should I export?
Export the most recent full month for the most accurate analysis. Partial months may underrepresent recurring costs like reserved instances and savings plans.

🔵 Google Cloud Platform (GCP)

GCP provides billing data through Billing Export to CSV or through BigQuery. The CSV export is the easiest method.

1
Open Cloud Billing
Go to the Google Cloud Console and navigate to Billing in the top-left menu.
2
Go to Reports
Click Reports in the left sidebar. Set the date range to the previous full month using the date picker on the right.
3
Export to CSV
Click the Download CSV button (the download icon in the top right of the chart area). This downloads a summary billing report.
4
Upload to Rackwyse
Upload the downloaded CSV to your Rackwyse dashboard.

Alternative: Billing Export via BigQuery

For more granular data, you can export GCP billing to BigQuery and then export from BigQuery to CSV. This provides SKU-level detail and is useful for large organisations with complex billing.

⚠️
BigQuery export requires setup
BigQuery billing export must be configured before billing data starts flowing. It does not retroactively export historical data. If you have not set this up yet, use the Reports CSV method above.

🔷 Microsoft Azure

Azure provides billing data through the Cost Management + Billing portal. You can download a usage details CSV directly.

1
Open Cost Management
Log in to the Azure Portal and search for Cost Management + Billing in the top search bar.
2
Go to Cost Analysis
In the left navigation, click Cost Management then Cost analysis. Select your subscription from the scope selector if prompted.
3
Set the date range
Use the date picker to select the previous full month. Change the view to Daily for more granular data.
4
Download CSV
Click the Download button (down arrow icon) and select Usage Details CSV. Choose the month and click Download.
5
Upload to Rackwyse
Upload the downloaded CSV to your Rackwyse dashboard.

Uploading to Rackwyse

Once you have your billing CSV from any provider:

1
Click + Upload Bill
On your dashboard, click the green + Upload Bill button in the top right, or click the Upload Bill button in the onboarding guide.
2
Select your file
In the file picker, select your billing CSV. Supported file types: .csv. Maximum file size: 50MB.
3
Wait for analysis
Rackwyse analyses your bill in under 60 seconds. You will see a progress indicator while the analysis runs. Do not close the tab.
4
Review your report
When the analysis completes, your report appears in the dashboard. Click on it to see your findings, estimated savings, and fix instructions.
