Uploading Bills (CSV)

Upload billing CSV exports directly — no cloud account connection required.

ℹ️
CSV uploads give billing-based findings. Cloud connections additionally enable utilization-based findings using CloudWatch data.

☁️ AWS — Cost Explorer CSV

1

Go to Cost Explorer

Log in to AWS → Billing → Cost Explorer. Direct URL: console.aws.amazon.com/billing

2

Set date range

Select previous calendar month. Granularity: Monthly. Group by: Service.

3

Download CSV

Click Download CSV in the top right.

4

Upload to Rackwyse

Dashboard → + New Analysis → Upload Bill CSV → select file → provider: AWS.

🔵 GCP — Cloud Billing CSV

1

Open Cloud Billing

Go to GCP Billing Console → your billing account → Reports.

2

Set time range

Select previous calendar month. Group by: Service.

3

Download CSV and upload

Click Download CSV. Upload to Rackwyse with provider: GCP.

🔷 Azure — Cost Management CSV

1

Open Cost Analysis

Go to Azure Portal → Cost Management + Billing → Cost Analysis.

2

Set scope and range

Select subscription scope. Time range: last month. Granularity: Monthly. Group by: Service name.

3

Download CSV and upload

Click Download → CSV. Upload to Rackwyse with provider: Azure.

File requirements

RequirementDetail
FormatCSV (.csv). Decompress .csv.gz before uploading.
Max file size50MB
Date rangeOne calendar month recommended.
