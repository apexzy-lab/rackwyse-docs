Uploading Bills (CSV)

If you prefer not to use a cloud connection, you can upload billing CSV exports directly. This works for all providers and requires no cloud credentials.

ℹ️
CSV uploads give you billing-based findings. Cloud connections additionally enable utilization-based findings (idle instances, over-provisioned resources) using CloudWatch/Cloud Monitoring data.

☁️ AWS — Cost Explorer CSV

1

Go to AWS Billing Console

Log in to AWS and navigate to Billing and Cost Management → Cost Explorer. Direct URL: console.aws.amazon.com/billing

2

Set the date range

Select the previous calendar month as your date range. Set granularity to Monthly. Group by Service.

3

Download the CSV

Click Download CSV in the top right. Save the file.

4

Upload to Rackwyse

On your Rackwyse dashboard, click + New Analysis → Upload Bill CSV, select the file, and choose AWS as the provider.

🔵 GCP — Cloud Billing CSV

1

Open Cloud Billing Console

Go to GCP Billing Console → select your billing account → Reports.

2

Set the time range

Select the previous calendar month. Set grouping to Service.

3

Download CSV

Click Download CSV. Save the file.

4

Upload to Rackwyse

On your dashboard, upload the file and select GCP as the provider.

🔷 Azure — Cost Management CSV

1

Open Azure Cost Management

Go to Azure Portal → Cost Management + Billing → Cost Analysis.

2

Set scope and time range

Select your subscription scope. Set the time range to last month. Set granularity to Monthly and group by Service name.

3

Download CSV

Click Download → CSV. Save the file.

4

Upload to Rackwyse

On your dashboard, upload the file and select Azure as the provider.

File requirements

RequirementDetail
FormatCSV (.csv). Decompress .csv.gz before uploading.
Max file size50MB
Date rangeOne calendar month recommended. Multi-month files work but findings use the full period total.
